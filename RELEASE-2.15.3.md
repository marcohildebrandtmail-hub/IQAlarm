# IQAlarm 2.15.3

Die Grundriss-Karte bietet im visuellen Home-Assistant-Karteneditor eine Auswahl der eingerichteten Grundrisse. Eine Karte kann nur Erdgeschoss, nur Obergeschoss oder alle Grundrisse anzeigen. Mehrere Karten speichern ihre Auswahl unabhängig.

Bestehende Karten und YAML-Auswahlen per Name oder ID bleiben gültig. Ohne Auswahl werden weiterhin alle Grundrisse angezeigt. Nach dem Update Home Assistant neu starten und den Browser neu laden.
